# Dashboard

Dashboard はデプロイ後に最初に確認するページです。

## 表示内容

- **認証情報数**：登録済みのアカウント数と有効なアカウント数。
- **API エンドポイント**：クライアントが使う `/v1` のベース URL。
- **利用状況**：選択期間のリクエスト数とトークン概要。

## 基本手順

1. `/dashboard` を開き、サービスに接続できることを確認します。
2. 有効な認証情報が 0 件なら **Credentials** でアカウントを認証します。
3. 画面に表示された API エンドポイントをコピーします。
4. **Credentials** でアクセスキーを作成し、SDK に URL とキーを設定します。

Dashboard は概要表示用です。変更は他のコンソールタブで行います。
