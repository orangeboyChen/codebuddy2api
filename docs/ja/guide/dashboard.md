# ダッシュボード

ダッシュボードはデプロイ後に最初に確認するページです。

## 表示内容

- **認証情報数 / 有効な認証情報数**：利用可能なアカウントがあるかを確認します。
- **API endpoint**：クライアントが使用する `/v1` のベース URL。
- **今日の呼び出し**：今日のリクエスト数、総トークン、キャッシュヒットトークン。

## 基本手順

1. `/dashboard` を開き、サービスに接続できることを確認します。
2. 有効な認証情報が 0 件なら **認証情報** でアカウントを認証します。
3. API endpoint をコピーし、**認証情報** で API key を作成します。
4. クライアントに endpoint と API key を設定します。

ダッシュボードは概要表示用です。変更は他のコンソールタブで行います。
