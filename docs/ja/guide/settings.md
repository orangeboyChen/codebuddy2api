# 設定

設定ではコンテナを再ビルドせずに実行時設定とコンソールのセキュリティを変更できます。

## サービス設定

- **CodeBuddy API エンドポイント**：既定値は `https://copilot.tencent.com` です。
- **認証モード**：自動認証またはトークン認証を選択します。
- **ネットワーク環境**：`internal`、`ioa`、`public` から選びます。
- **ログレベル**：サーバーログの詳細度を設定します。
- **管理者 Passkey RP ID**：WebAuthn に使うホスト名です。スキームやポートは含めません。

変更後に「保存」を押します。

## その他の設定

- **認証情報のモデル**：アカウントごとに利用可能なモデルを更新します。
- **利用イベントキャッシュ**：「利用イベントキャッシュを消去」で利用データを削除します。この操作は元に戻せません。
- **コンソールのセキュリティ**：管理者ユーザー名、パスワード、確認用パスワードを設定します。認証を有効にすると未ログイン利用者はログイン画面へ移動します。
