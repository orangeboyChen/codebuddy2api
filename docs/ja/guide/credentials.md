# 認証情報

認証情報は CodeBuddy アカウントとクライアント用 API key を管理します。

1. **認証情報** を開きます。
2. 「認証を開始」を押すか、「認証情報を手動追加」を選びます。
3. CodeBuddy のログインと認証を完了し、コンソールで「更新」を押します。
4. 「API key」で「API key を作成」を押し、secret をすぐに保存します。
5. リクエストには `Authorization: Bearer <access-key>` または `x-api-key: <access-key>` を使います。

保存済み認証情報では状態、期限、ドメイン、上流プロトコルを確認できます。「編集」と「削除」で管理します。期限切れのアカウントは再認証してください。
