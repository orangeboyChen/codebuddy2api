# 用量

用量页用于分析调用次数和 token 消耗。

## 筛选数据

1. 在“时间范围”选择 `24 hours`、`7 days` 或其他范围。
2. 在“凭据”和“API key”筛选具体来源，或保留全部。
3. 点击“刷新”重新读取数据。
4. 使用“自动刷新”设置定时刷新间隔。

## 阅读报表

- **Calls / Tokens / Cache-hit tokens**：当前筛选条件下的汇总。
- **Call trend**：按时间查看调用趋势，可对比不同模型。
- **Token trend**：按时间查看 token 趋势。
- **Credential usage**：按凭据查看调用次数和 token。
- **Model summary**：按模型查看调用次数、总 token 和缓存命中。

“Clear history”会清除已保存的用量事件，操作不可恢复。
