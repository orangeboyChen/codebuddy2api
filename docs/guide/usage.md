# 用量

用量页用于分析调用次数和 token 消耗。

## 筛选数据

1. 在“时间范围”选择 `24 hours`、`7 days` 或其他范围。
2. 在“凭据”和“API key”筛选具体来源，或保留全部。
3. 点击“刷新”重新读取数据。
4. 使用“自动刷新”设置定时刷新间隔。

## 阅读报表

- **调用次数 / 总 Tokens / 缓存 Token**：当前筛选条件下的汇总。
- **调用次数趋势**：按时间查看调用趋势，可对比不同模型。
- **Token 消耗趋势**：按时间查看 token 趋势。
- **凭证使用统计**：按凭据查看调用次数和 token。
- **模型汇总**：按模型查看调用次数、总 token 和缓存命中。

“清空历史”会清除已保存的用量事件，操作不可恢复。
