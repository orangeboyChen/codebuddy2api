# 账号状态

账号状态用于检查每个 CodeBuddy 账号还能使用多少额度、是否完成签到，以及可以调用哪些模型。

1. 点击「刷新全部」更新所有账号；只检查一个账号时，点击该账号的「刷新」。
2. 查看账号、套餐、已使用 / 总额、剩余百分比和「重置时间」。
3. 查看「签到」状态；按钮可用时点击「签到」，也可以使用「全部签到」。
4. 展开「模型（N 个）」，确认 API 测试或客户端要使用的模型。

每个模型会显示上游模型目录提供的信息：展示名与模型 ID（点击可复制）、倍率（如 `x3.33`）、模型介绍、以及「企业版 / 内部模型 / 免费」标记，并在下方标注上下文长度、输出上限和图像 / 工具 / 推理能力。默认展示前 8 个模型，点击「展开全部（N 个）」查看完整列表；展开后按钮变为「收起」，模型不超过 8 个时不显示该按钮。

模型目录来自上游 `/v3/config`，首次查询后会随凭据一起缓存，因此后续打开页面不会再请求上游。手动在「凭证管理」里修改模型列表后，被移除模型的元数据也会一并失效。

## 自动签到

每个账号的签到行下方都有「自动签到」开关，默认关闭。打开后选择一个时间，服务会在每天该时刻为该账号自动签到一次。

时间按**服务端本地时区**解释（与本项目其余部分一致，可用 `TZ` 环境变量指定）。调度器运行在网关进程内，因此只在网关运行时触发——如果部署在请求间隙会停止，则会在下一次轮询时补上。已签到的账号会被跳过；只有签到成功才会记录，失败的会在后续轮询重试，而不是等到第二天。

如果显示「额度未知」或查询失败，先到「凭证管理」确认账号仍然有效；如果账号正常，再到「Debug」查看最近的请求记录。
