# 凭证管理

凭证管理分为自动认证、API Key 和已保存的凭证三部分。

## 自动认证

1. 在“自动获取认证”区域点击“开始认证”。
2. 点击生成的“打开链接”，在 CodeBuddy 页面完成登录。
3. 返回控制台，等待自动检查认证状态；也可以点击“检查认证状态”。
4. 如果自动回调没有完成，点击“手动回调”，粘贴浏览器地址栏中的完整回调 URL 并提交。

## 手动添加凭证

点击“手动添加凭证”，填写 CodeBuddy Bearer Token；“用户 ID”可选。按上游接口需要选择“Chat”或“Responses”，再点击“保存”。

## API Key

1. 在“API Key”区域点击“创建 API Key”。
2. 输入名称，并选择要绑定的有效凭证。
3. 保存后立即复制 secret；列表中默认只显示脱敏值，需要时点击“查看 Key”。
4. 客户端请求使用 `Authorization: Bearer <API_KEY>` 或 `x-api-key: <API_KEY>`。

“已保存的凭证”中可以点击“刷新”“编辑”或“删除”。凭证过期后，重新完成自动认证或手动更新。
