# 凭据

凭据页管理 CodeBuddy 账号和对外 API key。

## 添加 CodeBuddy 账号

1. 在“自动认证”区域点击“开始认证”。
2. 在 CodeBuddy 页面完成登录和授权。
3. 返回控制台，点击“刷新”确认凭据已保存。
4. 如果不能使用 OAuth，也可以点击“手动添加凭据”。

## 创建 API key

1. 在“API key”区域点击“创建 API key”。
2. 输入名称并确认创建。
3. 立即复制 secret；之后只会显示脱敏值或需要点击“显示 key”。
4. 请求时使用 `Authorization: Bearer <access-key>` 或 `x-api-key: <access-key>`。

## 维护凭据

- 在“已保存的凭证”中查看“有效”、过期时间、域名和“上游协议”。
- 点击“编辑”修改凭据参数，点击“删除”移除账号。
- 账号过期后重新认证，不要把凭据 JSON 提交到仓库或文档站。
