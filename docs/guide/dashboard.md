# 仪表盘

仪表盘是部署后的第一站，用来确认服务是否可用。

## 页面内容

- **凭据总数 / 活跃凭据**：确认至少有一个可用的 CodeBuddy 账号。
- **API endpoint**：客户端使用的 `/v1` 基础地址。
- **今日调用**：今日请求次数、总 token 和缓存命中 token。

## 推荐操作顺序

1. 打开 `/dashboard`，确认页面能正常加载。
2. 如果活跃凭据为 0，进入“凭据”完成授权。
3. 复制 API endpoint，并在“凭据”页创建 API key。
4. 使用 endpoint 和 API key 配置客户端。

仪表盘只读；修改凭据、密钥或运行时参数请使用其他页面。
