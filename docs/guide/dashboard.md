# 仪表板

登录后先打开仪表板，确认代理服务和凭证池是否正常。

## 你会看到什么

- **总凭证数量**：已保存的 CodeBuddy 凭证总数；卡片下方显示其中的“有效”数量。
- **今日调用次数**、**今日总 Tokens**、**今日缓存 Token**：当天的请求和 Token 汇总。
- **API 服务端点**：客户端要使用的地址，通常以 `/v1` 结尾。

## 第一次使用

1. 如果“有效”数量为 0，打开“凭证管理”并完成一次认证。
2. 复制“API 服务端点”，再到“凭证管理”创建 API Key。
3. 将端点和 API Key 配置到客户端。
4. 仍有疑问时，到“API 测试”发送一条测试消息。
